# FDNPP Manifests

The authoritative CSV manifests are maintained in:

```text
Data_pre/cases/FDNPP/config
```

This directory is retained only for legacy notes or future non-authoritative
manifest documentation. Do not keep duplicate runtime CSV manifests here.

This case is a historical January 2025 snapshot. Its manifests and readiness
statements are preserved for reproducibility and are not the active FDNPP
configuration; use `Data_pre/cases/FDNPP` for current defaults and status.
