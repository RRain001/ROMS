# FDNPP Manifests

The authoritative CSV manifests are maintained in:

```text
Data_pre/cases/FDNPP/config
```

This directory is retained only for legacy notes or future non-authoritative
manifest documentation. Do not keep duplicate runtime CSV manifests here.

The active FDNPP ocean source is GLORYS12V1 with `N=40`. The
`config/staged_data_manifest.csv` file is retained for explicit HYCOM fallback
validation and must not be used as the active GLORYS readiness checklist.
