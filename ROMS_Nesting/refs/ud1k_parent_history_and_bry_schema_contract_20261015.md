**2026-10-15, Draft PR #3, stage: PREPRODUCTION INTERFACE TESTS ONLY.**

## Source authority and scientific status

ROMS native `ROMS_Nesting/roms_src/roms/Data/ROMS/CDL/bry_unlimit.cdl` is the upstream boundary NetCDF contract. Unlike initial-condition files, boundary fields have **four sides** and C-grid staggered lengths, and the history source is a different, larger parent domain. The accepted geometry for a *future* UD1K physical run is still only an **Option B candidate**: RHO 290×438, 96,104 ocean wet RHO cells in one connected component; RHO wet boundary 1,011, U wet boundary 1,005, V wet boundary 1,010; no coastline-crossing wet C-grid perimeter segments and no static parent interpolation source gaps. Original frozen UD1K / ES3K grids, mask sources, main and release configuration unchanged.

As of this commit, **no actual time-dependent ES3K ROMS history has been supplied/generated by this work**. The following code is a preflight admission gate, not a scientific hydrographic boundary generator.

## 1. Fail-closed history gate

[`ROMS_Nesting/Data_pre/nesting/ud1k_parent_history_contract.py`](../Data_pre/nesting/ud1k_parent_history_contract.py) accepts **explicit parent ES3K ROMS NetCDF grid + history file**, rejects unphysical or structurally inconsistent input and streams every wet history slice by time and sigma level rather than materializing an entire multi-month 3D data cube.

Parent must carry: C-grid `eta_rho,xi_rho,eta_u,xi_u,eta_v,xi_v` dimensions, `h,mask_rho,mask_u,mask_v,angle,lon_rho,lat_rho` with U/V native wet masks equal to the logical AND of adjacent wet RHO points; strictly positive parent wet depth; finite local parent angle.

History time must be **at least two strictly increasing CF `ocean_time` samples**, with parseable `"<unit> since <epoch>"` and a supported CF calendar; all source horizontal dimensions must match the ES3K grid exactly. Vertical metadata must be explicit and internally consistent: `Vtransform=2`, `Vstretching=4`, finite `theta_s,theta_b,hc,Tcline`, `s_rho,s_w,Cs_r,Cs_w` consistent with the ROMS stretching equations, `s_w=N+1`; other transformations are intentionally unsupported until independently implemented and tested.

All seven **source history fields** are mandatory with exact ROMS dimensions:

| Variable | Required parent history dimensions |
|---|---|
| `zeta` | `(ocean_time,eta_rho,xi_rho)` |
| `temp`, `salt` | `(ocean_time,s_rho,eta_rho,xi_rho)` |
| `u` | `(ocean_time,s_rho,eta_u,xi_u)` |
| `v` | `(ocean_time,s_rho,eta_v,xi_v)` |
| `ubar` | `(ocean_time,eta_u,xi_u)` |
| `vbar` | `(ocean_time,eta_v,xi_v)` |

Every wet source slice must be finite; masked/`_FillValue` at **wet** cells is rejected, while missing data at **dry** source cells are not mistaken for missing valid ocean samples. For every wet time slice, require `h+zeta>0`. `--metadata-only` runs the metadata admission audit but explicitly reports wet values **NOT_SCANNED_METADATA_ONLY**, not a full pass.

Future command **only after a true ES3K ROMS model solution exists**:

```bash
python ROMS_Nesting/Data_pre/nesting/ud1k_parent_history_contract.py \
  --parent-grid /absolute/path/to/ES3K_real_grid.nc \
  --history /absolute/path/to/ES3K_actual_roms_history.nc \
  --report /absolute/path/to/ES3K_actual_history_contract.json
```

A real parent history must reflect the approved ES3K case/epoch/temperature/salinity/velocity basis. Merely creating a correctly shaped history with constants is NOT a production source.

## 2. Complete 28-field ROMS boundary NetCDF **synthetic schema fixture only**

[`ud1k_bry_schema_contract.py`](../Data_pre/nesting/ud1k_bry_schema_contract.py) encodes `bry_unlimit.cdl` dimensions and mandatory `bry_time`, `s_rho/s_w`, `Cs_r/Cs_w`, geometry, and four sides × `zeta,temp,salt,u,v,ubar,vbar` = **28 boundary variables**.

Real native RHO/U/V lengths are represented without aliasing: for example, `zeta_south=(bry_time,xi_rho)`, `u_south=(bry_time,s_rho,xi_u)`, `v_south=(bry_time,s_rho,xi_v)`, `u_east=(bry_time,s_rho,eta_u)`, `v_east=(bry_time,s_rho,eta_v)`. All prepared side fields must be complete, finite and exact-shape; boundary NetCDF cannot overwrite an existing file or the parent grid. `SYNTHETIC_SCHEMA_TEST_ONLY_NOT_ROMS_PHYSICS` is embedded as a global attribute and a prominent warning. **The writing interface does not yet supply horizontal/vertical interpolation or source-based U/V fields**, and is intentionally synthetic-only to avoid accidental false physical deliverables.

Test-only invocation against real candidate B:

```bash
python ROMS_Nesting/Data_pre/nesting/ud1k_bry_schema_contract.py \
  --child-grid UD1K_CONNECTED_CORE_SHORELINE_CLEAR_COMPARISON_CANDIDATE.nc \
  --output SYNTHETIC_ONLY_UD1K41_bry.nc \
  --report SYNTHETIC_ONLY_UD1K41_schema.json \
  --synthetic-n-levels 41 \
  --synthetic-fixture-only
```

Never reference `SYNTHETIC_ONLY_UD1K41_bry.nc` as an input to a scientific UD1K run.
